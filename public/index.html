Ping = Mute system

          

            If a member’s nickname/display contains Ping = Mute (any fancy font),
            pinging them timeouts the pinger for 1 hour.

            Ping = Warn / Ping = Help also detected.

            Staff ranks are exempt.
          

          

            Protected users (env PROTECTED_USER_IDS): first ping warns with status;
            second ping → 1h timeout.
          

        

      


      

        

          
Anti-nuke rules

          

            Trusted (allowed to create channels/roles): Founder, Owner, Co-Owner, Manager, Head Admin


            Restricted (timeout 3 days + undo): Trial Staff, Stocker, Staff Team, Admin, Discord Dev


            Actions watched: channel/category create & delete, role create & delete, mass bans.

            Bot needs View Audit Log, Moderate Members, Manage Channels/Roles.
          

        

      


      

        

          
Reaction roles setup

          

            In Discord (staff):

            -rr setup 🎉 @Events 📢 @Announce


            Posts a message: “React with 🎉 to get Events…” and assigns roles on react.

            Bot role must be above those roles and have Manage Roles.


            After every redeploy, run -rr setup again (Render storage is temporary).
